Rug Radar

LPs learn about a drain after the fact. Agents could watch every pool 24/7 — but only if they can buy live intelligence per call, with no API keys, no subscriptions, and a receipt they can prove.

What it is

An x402-metered DeFi risk service — drain scores, whale flows, lending stress — and an autonomous agent with its own wallet that finds it, pays for it, and decides.

Why now

x402 gives machines a pay-per-request rail. Standardized subgraphs give one schema across protocols. ENSv2 gives services a name and a permission model. We wired all three.

Built from scratch

4 packages, 7 protocols, 2 chains, 1 hackathon. Everything in this deck ran for real on testnets.

How one question becomes a paid, audited decision

Discover on ENS → pay with x402 on Hedera → reason over The Graph

1 · DISCOVERAgent resolves api.rugradar.eth through the ENSv2 Universal Resolver: endpoint, prices, pay-to account, audit topic. Nothing hard-coded.
2 · QUOTEService answers 402 with a metered price — per protocol, per lookback day, per 15-second stream window. HBAR or HTS USDC.
3 · PAYBudget guard checks the quote before signing. Blocky402 verifies + settles on Hedera in ~1 s; facilitator pays the fee.
4 · DATAOne standardized query runs on Uniswap v3/v2, SushiSwap, Curve, Aave v3, Compound v3, Spark. Substreams feed the live whale wire.
5 · PROVESettlement, agent spend and the final verdict are written to two Hedera Consensus Service topics. Failed data = payment cancelled.

Three bounties, one product

Hedera · AI & Agentic Payments

  • Live x402 service on Hedera testnet, settled via Blocky402
  • Metered pricing + streamed 15 s windows (SSE)
  • HBAR and HTS USDC in the settlement path
  • HCS audit trail: every settlement, every agent decision
  • ERC-8004 registration file; discovery directory via ENS

The Graph · Composable / Standardized

  • One query string, seven protocols (Messari dex-amm + lending schemas)
  • Substreams ethereum-common composed with a standardized subgraph for pricing
  • All data live from The Graph Network gateway — no mocks
  • Schema drift handled in one line (from vs account{id})

ENS · Best Use of ENSv2

  • rugradar.eth runs its own PermissionedRegistry + Resolver
  • Services are expiring, non-transferable, revocable subnames
  • ENSIP-26 agent-endpoint[x402] + x402.* records
  • Enhanced Access Control: service key may edit only x402.pricing
  • Agents as namespaces: scout.rugradar.eth

Beyond the hackathon

The pattern for any data an agent should find and pay for on its own

Mainnet is a config flip

HEDERA_NETWORK=mainnet + the mainnet Blocky402 URL. Same code, same ENS name; records move with the name. Free-tier Render deployment already public.

Who pays

LP bots, treasury monitors, and other agents — priced per call in cents. Providers list one name, set one price record, and get paid in HBAR or USDC with an on-chain receipt.

Next

More standardized protocols (one JSON entry each), Substreams-native drain detection, ERC-8004 reputation from HCS receipts, and a marketplace of *.rugradar.eth services with delegated pricing rights.
